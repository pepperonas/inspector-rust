### Roter Zustand — dokumentiert, NICHT gefixt (Phase-0-Vorgabe)

**R1 — `cargo`-Build der Tauri-Shells bricht ab (stale `clip-snap`-Pfad im `target/debug`).**
- Fehler (identisch für macos/win/linux Shell):
  ```
  failed to read plugin permissions: failed to read file
  '/Users/martin/claude/clip-snap/target/debug/build/tauri-*/out/permissions/app/autogenerated/commands/app_hide.toml':
  No such file or directory (os error 2)
  ```
- **Ursache:** Das Repo wurde von `/Users/martin/claude/**clip-snap**` nach `…/inspector-rust` umbenannt/verschoben. Cargo hat absolute `OUT_DIR`-Pfade im **debug**-`target/`-Cache eingebrannt (tauri-build Plugin-Permissions). Der Release-Cache wurde diese Session bereits via `cargo clean --release` bereinigt (Release-Build/Install v0.55.0 läuft sauber) — der **debug**-Cache nicht.
- **Kein Quellcode-Defekt:** Auf einem frischen Clone / in CI tritt das nicht auf (kein stale Cache). Es ist ein **lokaler Build-Cache-Artefakt**.
- **Trivialer Fix (bewusst aufgeschoben, nicht Teil von Phase 0):** `cargo clean` (oder gezielt `cargo clean -p inspector-rust-macos -p inspector-rust-win -p inspector-rust-linux -p tauri`), dann erneut bauen. → Kandidat für Phase D (Umgebungs-Hinweis), nicht für einen Source-Fix.
- **Effekt aufs Gate:** Solange der debug-Cache stale ist, sind `pnpm check` und `cargo test --workspace` lokal nicht grün zu bekommen. Die inhaltliche Rust-Test-Aussage liefert ersatzweise `cargo test -p inspector-rust-core` (298 grün).

**R2 — clippy nicht installiert.**
- `cargo clippy` fehlt → `scripts/check.sh` nutzt den dokumentierten Fallback `cargo check --workspace` (der dann an R1 scheitert).
- Fix (Umgebung, aufgeschoben): `rustup component add clippy`. Das Gate verlangt clippy `-D warnings`; aktuell nicht erfüllbar bis clippy + R1 behoben sind.

**R3 — eslint 20 errors (vorbestehend, eslint-plugin-react-hooks v6).**
- Betroffene Dateien (ich habe sie diese Session NICHT angefasst bzw. die Fehler nicht verursacht):
  - `core/frontend/src/components/PreviewPanel.tsx`
  - `core/frontend/src/components/BpmDetector.tsx`
